# Data Cleaning and Exploratory Data Analysis

## Project Overview
This repository contains a collection of data cleaning and exploratory data analysis projects completed during my internship at Codveda. The projects demonstrate proficiency in data preprocessing, cleaning, visualization, and analysis using Python and various data science libraries.

## Repository Structure
- `data_cleaning_techniques.ipynb`: Comprehensive demonstration of data cleaning methodologies
- `exploratory_data_analysis.ipynb`: In-depth exploratory data analysis with visualizations
- `feature_engineering_preprocessing.ipynb`: Feature engineering and data preprocessing techniques

## Technologies Used
- Python 3.x
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Descriptions

### Data Cleaning Techniques
This notebook demonstrates various data cleaning techniques including:
- Handling missing values
- Removing duplicates
- Fixing inconsistent data
- Data type conversion
- Outlier detection and treatment
- String manipulation and text cleaning
- Date-time formatting

### Exploratory Data Analysis
This notebook covers comprehensive exploratory data analysis including:
- Univariate analysis
- Bivariate analysis
- Multivariate analysis
- Statistical summaries
- Distribution analysis
- Correlation analysis
- Visual exploration using various plot types

### Feature Engineering & Preprocessing
This notebook focuses on:
- Feature selection and extraction
- Feature transformation
- Normalization and standardization
- Encoding categorical variables
- Dimensionality reduction
- Data preparation for machine learning models

## Setup and Installation
1. Clone this repository
```bash
git clone https://github.com/ShohanRony/Codveda-Intership-level1-data-cleaning-eda.git
```

2. Install the required dependencies
```bash
pip install -r requirements.txt
```

3. Launch Jupyter Notebook
```bash
jupyter notebook
```

## Usage
Open the Jupyter notebooks to view the analysis and code. Each notebook is self-contained with detailed comments and explanations for each step of the data cleaning and analysis process.
